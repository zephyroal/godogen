# 堡垒冲刺 Fortress Rush

2.5D 斜 45° 大方块像素（MC 风）· 地铁跑酷式移动 · 双阵营推塔对抗原型。
策划案原文见本目录下的 `MiniGame.5D，MC式大块像素，地铁跑酷移动逻辑）` 文件。

- **引擎**：Godot 4.7.1 .NET（C#），Jolt 物理，正交等距摄像机
- **美术**：全程序化方块生成（无外部资产、零 API 成本 —— 正契合 MC 大方块风格）
- **宿主**：本仓库为 Windows 本地开发的游戏仓库（godogen 源仓库的发布目标形态）

## 需求分解（源自策划案）

| 需求 | 原文要点 | 原型落地 |
|------|----------|----------|
| 视角美术 | 2.5D 斜 45°，MC 式大块像素，蓝左红右 | 正交等距摄像机 + 程序化方块（颜色抖动的 BoxMesh） |
| 地图结构 | 每阵营 10 座城池，1=简易前哨 → 10=终极主城，复杂度递增 | 长条形双列地图；城池占一段纵深，墙体行数/密度/高度/血量随编号增长 |
| 城池=迷宫 | 内部巷道可绕路、卡位，可兜圈战斗 | 每行至少留 1 条空巷道；巷道阻挡物可被爆破拆除 |
| 移动逻辑 | 地铁跑酷式：持续向前跑，可左右变道、闪避，不能站死，可急转进城池 | 自动奔跑（朝向 ±Z），A/D 变道（6 条巷道跨双阵营），S 掉头折返（防守用），撞墙即停需绕行或爆破 |
| 核心循环 | 攻敌 1→10 号城池；同时防守自家；可折返拦截 | 蓝方（玩家+2 AI 队友）攻红线，红方 3 AI 攻蓝线；掉头回家防守 |
| 城池血量 | 每座有总血量，归零被摧毁，变成废墟不可再用 | 方块各自有血量并计入城池总量；核心水晶占比血量；摧毁后变灰色废墟、失去复活点功能 |
| PvP | 途中遭遇互放技能；被击败倒地，就近完好城池复活 | 爆破（范围伤方块+角色）、冲刺撞击（伤角色+撞碎薄墙）；死亡 3s 后在己方最近完好城池复活 |
| 胜负 | 摧毁敌方 10 号主城获胜；失败方展示被摧毁城池列表 | 摧毁敌方 10 号→胜利结算；己方 10 号被摧毁→失败结算+列表；R 重开 |
| 编号标注 | 每座城池上方标注 1-10 | Label3D 悬浮标牌（编号+血量条） |

### 阵营与地图布局（南→北）

```
[蓝方出生点] 蓝10 蓝9 … 蓝2 蓝1 ‖中立带‖ 红1 红2 … 红9 红10 [红方出生点]
   x<0 蓝方城池列（巷道 x=-13.5/-7.5/-1.5）      x>0 红方城池列（巷道 x=+1.5/+7.5/+13.5）
```

- 蓝方向北（-Z）奔跑进攻红线；红方向南（+Z）进攻蓝线
- 巷道贯通全图：玩家可持按变道键跨过中线回防自家城池

## 操作

| 键 | 功能 |
|----|------|
| A / ← | 左变道 |
| D / → | 右变道 |
| S / ↓ | 掉头折返（回防自家城池） |
| 空格 / J | 范围爆破（伤敌方方块与角色） |
| Shift / K | 冲刺撞击（伤敌方角色、撞碎薄墙） |
| R | 结算界面重开 |

## 构建与运行

```bash
dotnet build
godot --headless --import          # 首次或资产变更后
godot .                            # 运行游戏（或直接开编辑器）

# 逻辑探针（无渲染，每5秒打印战况，验证 AI 攻城/胜负判定）
godot --headless --script test/SimProbe.cs

# 证明视频（确定性捕获：完整比赛弧线 ~46s + 结算画面）
godot --write-movie screenshots/result/frame.png --fixed-fps 30 --quit-after 1950 --script test/Presentation.cs
ffmpeg -y -framerate 30 -start_number 0 -i "screenshots/result/frame%08d.png" -frames:v 1580 \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart screenshots/result/video.mp4
```

> 引擎路径：`D:\godogen\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe`（Windows 本机）。
> 证明产物：`screenshots/result/video.mp4`（~53s）+ `screenshots/01..06_*.png` 关键帧。
> ffmpeg（winget 版）不支持 `-pattern_type glob`，用 `frame%08d.png` 序号模式；Windows 环境无需 xvfb。

## 已知设计取舍

- 结算列表按数字排序（蓝1→蓝10）；比赛节奏 ~45-60s（原型速度，可调 `Fortress.cs` 中方块血量）
- AI 会在过冲整座城池纵深后折返扫荡；玩家死亡就近复活于己方最近完好城池
- 无音频（godogen 运行时不带音频管线）；美术全程序化，无付费 API 依赖
