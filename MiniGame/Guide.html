🏰 堡垒冲刺 Fortress Rush — 架构与操作指南

2.5D 体素风格·地铁跑酷式移动·双阵营推塔对抗原型 · Godot 4.7.1 .NET (C#)

📋 快速操作（双击 .bat 即可）

项目根目录 D:\godogen\MiniGame\ 下提供以下快捷脚本：

脚本功能说明
open_editor.bat打开 Godot 编辑器加载当前项目，可直接编辑场景、调试运行
build.bat编译 C# + 导入资源dotnet build + godot --headless --import
run_game.bat直接运行游戏先 build 再启动窗口模式，跳过编辑器
sim_probe.bat逻辑探针无渲染跑一局 AI vs AI，每 5s 打印战况
record_video.bat录制证明视频确定性捕获 90s 帧序列 + ffmpeg 编码 mp4
export_web.bat导出 Web 版生成可部署的 HTML5 WebGL 构建

🎮 如何用编辑器打开场景

方法一：双击 open_editor.bat

自动打开 Godot 编辑器并加载 MiniGame 项目。

方法二：命令行

cd D:\godogen\MiniGame
"D:\godogen\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe" --editor .
注意：必须使用 mono 版 Godot（Godot_v4.7.1-stable_mono_win64.exe），普通版不支持 C#。

编辑器内操作

  1. 左侧 文件系统 → res://scenes/Main.tscn 双击打开场景
  2. Main.tscn 只是一个根节点（挂了 Game.cs 脚本），世界在运行时由 C# 代码动态构建
  3. 按 F5（或▶按钮）运行游戏
  4. 按 F6 运行当前场景（跳过主场景选择）
  5. 修改 scripts/*.cs 后，编辑器会自动检测并重新编译

🔨 如何编译游戏

方法一：双击 build.bat

执行两步：C# 编译 + Godot 资源导入。

方法二：命令行

cd D:\godogen\MiniGame

# 1. 编译 C# 程序集（生成 bin/Debug/net8.0/FortressRush.dll）
dotnet build

# 2. 导入 GLB/贴图等资源（首次或新增资产后必须执行）
"D:\godogen\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe" --headless --import

# 3. 运行游戏
"D:\godogen\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe" .
工具链版本：Godot 4.7.1 stable mono · .NET SDK 10.0.300 (net8.0 target)

🌐 如何导出 Web 版

前置准备

  1. 在 Godot 编辑器中，菜单 Editor → Manage Export Templates
  2. 下载 Web (HTML5) 导出模板（约 ~50MB）

方法一：双击 export_web.bat

自动导出 Web 版到 export/web/ 目录。

方法二：命令行

cd D:\godogen\MiniGame

# 先确保 C# 已编译
dotnet build

# 导出 Web 版（需要已下载导出模板）
"D:\godogen\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe" \
  --headless --export-release "Web" export/web/index.html
注意：首次导出前必须在编辑器中配置 Export Preset。
菜单 Project → Export → Add → Web (HTML5)，保存即可（默认配置可用）。
Web 导出需要 threads: off（C# 在 Web 端不支持多线程）和 extension: on。

本地预览 Web 版

cd D:\godogen\MiniGame\export\web
python -m http.server 8080
# 浏览器打开 http://localhost:8080

🏗️ 代码架构

目录结构

MiniGame/
├── project.godot              # Godot 项目配置（引擎版本、入口场景、显示设置）
├── FortressRush.csproj        # .NET 项目文件（SDK 引用、目标框架）
├── scenes/
│   ├── Main.tscn             # 唯一场景（根节点挂 Game.cs，运行时动态构建世界）
│   └── BuildMain.cs          # 构建期场景生成器（headless 运行→输出 .tscn）
├── scripts/                   # 运行时 C# 代码
│   ├── Game.cs                # 游戏根节点：世界构建、相机、游戏流程
│   ├── Fortress.cs            # 城池：迷宫方块、围墙 compound、核心水晶、崩塌动画
│   ├── Runner.cs              # 角色：跑酷移动、爆破/冲刺技能、AI 逻辑、回防拦截
│   ├── Block.cs               # 可破坏方块（城墙/核心水晶的基类）
│   ├── HUD.cs                 # UI 层：拔河计分条、血量、技能冷却、结算屏
│   ├── FX.cs                  # 特效系统：爆炸光球、激光束、冲击波、冲刺残影
│   └── Glb.cs                 # GLB 模型加载器（AABB 测量、缩放对齐、缺失回退）
├── assets/glb/                # GLB 3D 模型 + PBR 贴图
├── test/                      # 测试与捕获脚本
│   ├── SimProbe.cs            # 逻辑探针（headless，AI vs AI，每 5s 报告战况）
│   ├── Presentation.cs        # 证明视频捕获（确定性输入时间线→帧序列）
│   ├── ModelPreview.cs        # GLB 朝向预览（4 向截图）
│   └── FxProbe.cs             # 特效验证探针
├── screenshots/               # 截图与视频输出（gitignored）
├── 3DModel/                   # 3D 模型需求与差距分析文档
└── README.md                  # 项目说明

核心类关系

Game (Node3D)  ← 根节点，挂在 Main.tscn 上
├── WorldEnvironment / DirectionalLight3D / Camera3D    ← 环境 & 相机
├── MultiMeshInstance3D (地面棋盘)                       ← 程序化地形
├── Fortress × 20 (Node3D)                               ← 蓝红各 10 座城池
│   ├── Block × N (MeshInstance3D)                       ← 可破坏方块（墙/核心）
│   ├── GLB compound / castle / tower                    ← 建筑模型
│   └── Label3D                                          ← 编号+血条标牌
├── Runner × 6 (Node3D)                                  ← 1 玩家 + 5 AI
│   └── MeshInstance3D × 6                               ← 方块人身体部件
├── HUD (CanvasLayer)                                    ← UI 覆盖层
└── FX 节点（BlastFx / LaserFx / HitSparkFx / DashTrailFx）← 临时特效

运行时流程

Game._Ready()
  ├── BuildEnvironment()        # 天空盒、灯光、相机
  ├── BuildGround()             # 地面棋盘 + 公路标线 + 路标 + 金币 + 远景城堡
  │   ├── BuildScenery()        # 松树(GLB) + 阔叶树(GLB) + 灌木(GLB) + 岩石
  │   ├── BuildCoins()          # 公路金币(GLB)
  │   ├── BuildCamps()         # 两端营地（石台+旗杆+GLB spawn_pen）
  │   └── BuildLandmarkCastle() # 远端 castle_terminal 地标(GLB)
  ├── BuildFortresses()         # 20 座城池（蓝左红右，同 Z 对峙）
  │   └── Fortress.Build()      # 每座城池：
  │       ├── 方块迷宫墙        #   可破坏 Block（hp=20）
  │       ├── 核心水晶          #   发光 Block（受击闪光）
  │       ├── BuildGate()      #   发光城门光幕
  │       ├── BuildWalls()     #   GLB compound 围墙
  │       ├── GLB watchtower × 2  # 门前瞭望塔
  │       └── GLB castle keep  #   1号城+10号城放城堡模型
  ├── SpawnRunners()           # 6 名角色（2蓝AI+3红AI+1玩家）从南端出生
  └── HUD                      # UI 初始化

Game._Process(delta)           # 每帧：
  ├── 追尾相机跟随玩家          #   平滑 lerp + 震屏
  ├── Runner._Process()        #   自动奔跑 + 变道 + 技能 + AI
  ├── Fortress.TickVisuals()   #   核心脉动 + 受击闪光 + 崩塌动画
  ├── HUD._Process()           #   血量/冷却/计分更新
  └── 终局检测                  #   10号城被摧毁→EndGame→环绕镜头

AI 行为树

Runner.Think() (每 0.25s)
  ├── TryDefend()              # 优先：己方城池被入侵→最近 AI 折返拦截
  ├── 选择目标                  # 敌方最低编号完好城池
  ├── 路径策略                  # 己方侧跑路→接近目标 14m 内切入敌方巷道
  ├── SteerToBlocks()          # 横向偏向最近存活的敌方方块
  ├── 遭遇战                   # 近身敌人→冲刺撞击
  └── 拆墙                     # 被墙卡住→爆破→换巷道

关键调优参数（Game.cs）

参数值说明
RunSpeed9角色自动奔跑速度
BlastBlockDmg70爆破对方块的伤害
DashBlockDmg45冲刺对方块的伤害
BlastCd / DashCd2.2s / 3.5s技能冷却
墙血量20方块城墙 HP（Fortress.cs）
核心血量90+12×编号核心水晶 HP（+50 给 10 号城）
回防阈值30%城池血量低于此值不再触发回防

操作说明

按键功能
A / ←左变道
D / →右变道
S / ↓掉头折返（回防自家城池）
空格 / J范围爆破（伤敌方方块与角色）
Shift / K冲刺撞击（伤敌方角色、撞碎薄墙）
R结算界面重开
