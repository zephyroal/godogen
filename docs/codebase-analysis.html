01项目本质：不是游戏，是"生成器的源码"

Godogen 不是游戏，也不是应用程序 —— 它是一条自主游戏生成流水线的输入源。其核心模型为：

godogen 源仓库
manifest + 引擎指南 + asset-gen 技能 ──publish.sh──▶ 游戏运行仓库
CLAUDE.md/AGENTS.md + 指南 + 技能 ──agent 构建──▶ 游戏本体
由 Claude Code / Codex 现场生成

用户给出一段游戏简报，宿主智能体（Claude Code 或 Codex）在已发布的游戏仓库内自主完成：搭建项目脚手架 → 调用付费 API 生成美术资产 → 运行引擎 → 从运行中的游戏验证结果（直播 URL 或 15–20 秒录像），而非仅凭"编译通过"作数。

发布出的运行仓库刻意保持"薄"：只有一份运行时清单、一页引擎指南、一个资产生成技能。项目脚手架、捕获工具等一切其余内容由智能体依据指南现场重建 —— 信任模型，不预置脚手架。

03发布流水线（publish.sh）

# 引擎 × 宿主智能体均为发布期渲染选项，而非独立源树
./publish.sh --engine godot|bevy|babylon --agent claude|codex --out <目录> [--force]
  1. 技能：asset-gen/ → <out>/.claude/skills/asset-gen/（Claude）或 <out>/.agents/skills/asset-gen/（Codex），经 render_dir.py 做 token 替换；Codex 额外生成 agents/openai.yaml。
  2. 清单：prompts/runtime.md → <out>/CLAUDE.md 或 AGENTS.md，渲染引擎/智能体 token。
  3. 引擎指南：engines/<engine>.md 按字面拷贝为 <out>/<engine>.md。
  4. .gitignore（仅目标缺失时生成）+ git init 目标仓库。
渲染 Token取值（按目标）
${ENGINE_NAME} / ${ENGINE_GUIDE_FILE}Godot/Bevy/Babylon.js 与 godot.md/bevy.md/babylon.md
${AGENT_NAME}Claude 或 Codex
${ASSET_SKILL_COMMAND}Claude：/asset-gen；Codex：$asset-gen
${ASSET_GEN_SKILL_DIR}技能安装后的实际路径
${RUNTIME_ASSET_DIR}Babylon 为 src/assets，其余为 assets

04三份引擎指南要点

🟦 Godot 4

C# / .NETJolt构建期场景生成
  • 所有 C# 类必须 partial；.csproj 版本字段匹配本机工具链
  • 场景由 headless SceneTree 脚本一次性生成 .tscn（含 PackAndSave 验证范式）
  • 静默陷阱：Owner 链、GLB 递归内联（100MB+ 文件）、SetScript() 释放包装、MultiMesh+GLB、C# 枚举名
  • 录屏：--write-movie + --fixed-fps 30 + ffmpeg 合成 mp4

🦀 Bevy

Rust / ECS离屏捕获
  • 锁定 cargo add bevy 解析出的确切版本；所有 bevy_* 同 minor
  • API 以本机 ~/.cargo/registry 内源码为准（版本常新于训练数据）
  • 陷阱：glTF jpg 纹理需 features=["jpeg"]、UI 属性在 Node 组件内、程序网格背面剔除
  • 录屏：专用离屏二进制 + RenderTarget::Image + 手动时间步

🟨 Babylon.js

TypeScript / Vite直播 URL
  • dev server 绑 0.0.0.0:5173 —— 用户实时观看的入口
  • 陷阱：副作用导入被 tree-shake 丢弃（编译过、运行时抛错）
  • Havok 物理：HavokPhysics.wasm 从 public/ 提供
  • 捕获：headless Chrome + 真 GPU（防 SwiftShader 假渲染），等就绪标志后再截图

05设计哲学与编辑规则（AGENTS.md，对本仓库有约束力）

四大设计支柱

  • 证明胜过宣称 —— 以运行中的游戏（录像/URL）为验收标准，编译通过不作数
  • 信任模型 —— 不预置脚手架、不预置规划器；指南只写模型推断不出的东西
  • 成本感知 —— 每次生成前向用户确认花费；资产清单记录路径/尺寸/成本
  • 一份源多目标 —— 引擎与宿主智能体都是同一源树的渲染期选择

编辑硬规则

  • ❌ 禁止在本源仓库创建/维护 .claude/skills/ 或 .agents/skills/（发布期产物）
  • ❌ 不写"显而易见"的指南 —— 交付物（录像/URL）自会暴露模型的错误
  • ✅ 改动/删除功能时，按新设计本来的样子描述，不写过渡说明
  • ✅ 贡献：先开 Issue 获批再写码；改动最小化、外科手术式

静态 3DTripo3D 图转模型30¢（默认）/ 60¢（HD）道具、场景物
绑骨 3DTripo3D biped网模 + 25¢双足角色（非人形自动中止）
动画重定向Tripo3D 预设（100+ 个 biped 动作）10¢/片段复用绑骨结果，免重复付费
关键防坑：绝不提示词要"透明背景"（会画出棋盘格）—— 要纯色背景再用 rembg 抠；Tripo3D 超时不代表失败，任务 id 已存 sidecar，用 resume 免费续接，重新提交会双倍扣费。

工具功能
