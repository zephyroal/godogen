3. 导出 Web（HTML5）

前提：需下载 Godot Web 导出模板（Editor → Editor Manager → Export Templates → Download）。

  1. 用编辑器打开项目（open_3dchess.bat）
  2. 菜单 Project → Export...
  3. 点 Add... → 选 Web (HTML5)
  4. 导出路径设为 D:\godogen\3DChess\export\web\
  5. 点 Export Project

命令行导出（需先在编辑器中配置好 export_presets.cfg）：

"D:\godogen\Godot_v4.7.1-stable_mono_win64\Godot_v4.7.1-stable_mono_win64_console.exe" --headless --path "D:\godogen\3DChess" --export-release "Web" "D:\godogen\3DChess\export\web\index.html"

⚠ Godot 4.7 C# (Mono) 项目导出 Web 需要 .NET 8 Web 构建工具链。SDFGI / Glow 等高级渲染特性在 WebGL 下可能不支持，导出前建议在 export preset 中关闭 SDFGI。

4. 代码架构

文件职责
Rules.cs规则引擎：走法生成、合法性过滤、将军检测（含飞将）、绝杀/困毙判定
AI.csnegamax + α-β + 静态搜索 + MVV-LVA 排序 + 迭代加深（~0.9s 时限）
Board.cs程序化木纹棋盘、网格线、楚河汉界、标记系统（选中/落点/将军/上一步/悬停）
Piece.cs车削立体棋子几何（底盘→桶身→肩环→穹顶）+ 木纹漆面 + 刻字 + 移动/受击/死亡动画
Game.cs根节点：相机/灯光/环境（SDFGI+Glow+Filmic+SSAO）、棋子生成、点击拾取、走子流程、AI 调度、悔棋/重开
HUD.csCanvasLayer UI：模式选择、回合条、将军闪、终局结算（锚点自适应布局）
FX.cs程序化木纹纹理生成器 + 碎屑粒子
BuildMain.cs构建期场景生成（headless 运行一次 → 输出 Main.tscn）
RulesProbe.csheadless 规则断言探针（21 项，含 AI 合法性验证）
Presentation.cs确定性证明视频捕获（注入输入 + 截图）

5. 游戏流程

_Ready() 构建世界→ BuildEnvironment（天空/GI/灯光/相机）→ Board（棋盘/线条/楚河汉界/标记）→ SpawnPieces（32 枚棋子）→ HUD（模式选择界面）
玩家点击棋子→ 规则引擎生成合法落点→ 玩家点击落点→ 走子动画→ 检查将军/绝杀/困毙→ AI 思考（后台线程）→ AI 走子→ 循环至终局
