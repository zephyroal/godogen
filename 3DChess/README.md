# 3D 中国象棋 Xiangqi3D

全 3D 中国象棋（Xiangqi）：木纹棋盘 + 车削立体棋子 + 触屏操作 + 内置 AI 对手。
与 MiniGame 同级的独立 Godot 项目（godogen 工作区）。

- **引擎**：Godot 4.7.1 .NET（C#），正交于 `D:\godogen\Godot_v4.7.1-stable_mono_win64\`
- **模式**：人机对弈（执红 vs AI 黑）· 双人对弈
- **美术**：全程序化生成（车削棋子几何 + Label3D 刻字 + 光影材质），零外部资产零 API 成本
  （拟真卡通化棋子模型升级需求：见 [3DModel/3DModelRequirements.md](3DModel/3DModelRequirements.md)）
  （如后续接入 3D 生成工具，可按 `../MiniGame/3DModel/3DModelRequirements.md` 模式升级为生成模型）

### 走法规则清单（引擎必须完整实现）

- **帅/将**：九宫内直走一格；两帅不得照面（将帅对脸判非法）
- **仕/士**：九宫内斜走一格
- **相/象**：田字斜走两格，不过河，塞象眼非法
- **马**：日字，蹩马腿非法
- **车**：直线任意步，不可越子
- **炮**：直走不隔子；吃子必须隔恰好一子（翻山）
- **兵/卒**：过河前只进一；过河后可进可平，永不后退
- 送将非法（走完自己被将/两帅照面均判非法）；无合法着法时：被将=绝杀，不被将=困毙，皆负

### AI（人机模式）

negamax + α-β 剪枝，迭代加深（时间上限 ~0.8s，深度 2–4），子力价值（车900/炮450/马400/士象200/兵100，过河兵加值）+ 位置项（兵推进、马活跃度、帅安全），吃子优先排序，等分随机扰动避免每局雷同。

### AI

negamax + α-β 剪枝，**迭代加深至深度 8**（0.9s 时限保护，超时层安全丢弃）；**静态搜索**（吃子延伸至静止，消除视野效应）；MVV-LVA 排序（先按被吃子价值）；评估含子力 + 兵推进 + 马活跃度 + 帅防（仕象存活数）+ 九宫联防；等分随机变着避免雷同。初始局面深度 8 仅 ~40ms/2k 节点。

## 操作

| 手势/按键 | 功能 |
|----------|------|
| 单指点击（或鼠标左键） | 选中己方棋子 → 显示合法落点 → 点击落点走子 |
| 单指拖动（或鼠标右键拖动） | 旋转视角（俯仰/偏航限位） |
| 双指捏合（或滚轮） | 缩放视角 |
| U | 悔棋（人机模式一次撤两手） |
| R | 终局后重开（同模式快速重开） |
| 菜单按钮 | 返回模式选择界面 |

## 构建与运行

```bash
dotnet build
godot --headless --import
godot .

# 规则探针（headless 断言规则引擎）
godot --headless --script test/RulesProbe.cs

# 证明视频（确定性捕获）
godot --write-movie screenshots/result/frame.png --fixed-fps 30 --quit-after 900 --script test/Presentation.cs
ffmpeg -y -framerate 30 -start_number 0 -i "screenshots/result/frame%08d.png" -frames:v 900 \
  -c:v libx264 -pix_fmt yuv420p -movflags +faststart screenshots/result/video.mp4
```
